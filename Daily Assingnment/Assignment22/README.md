# ASP.NET Core REST API

## Project Overview

This project is a RESTful Web API developed using ASP.NET Core. It demonstrates the implementation of CRUD (Create, Read, Update, Delete) operations using Controllers, Models, Services, and Dependency Injection. The API is documented and tested using Swagger.

---

## Features

- Create Resource
- Read Resource
- Update Resource
- Delete Resource
- Search by ID
- Search by Name
- Search by Category/Department
- Dependency Injection
- Swagger API Documentation

---

## Technologies Used

- ASP.NET Core Web API
- C#
- .NET 8
- REST API
